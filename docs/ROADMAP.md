# Roadmap

## Phase 0: Project Bootstrap

- Create repository
- Define product direction
- Define safety boundary
- Define MVP scope
- Decide upstream strategy after checking original LeagueAkari license

## Phase 1: MVP

- Client connection
- Current summoner profile
- Recent 20 matches
- Champion select detection
- Rune recommendation with confirmation
- Rule-based composition analysis
- CN/global compatibility notes

## Phase 2: Data Quality

- Champion tag database
- Patch data update flow
- Matchup and synergy data source
- Local cache
- Data confidence display

## Phase 3: Personalization

- Personal champion pool
- Role preference
- Champion comfort score
- Draft suggestions based on what the user can actually play

## Phase 4: Extensibility

- Plugin API
- Theme system
- Local data-source adapters
- Optional community-maintained champion tag packs

## Phase 5: Release

- App signing strategy
- Auto update
- Installer
- Release notes
- User documentation
