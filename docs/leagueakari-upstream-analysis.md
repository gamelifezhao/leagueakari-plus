# LeagueAkari 原版功能分析

> 目标：只学习和移植“理解对局”的能力，不做影响公平性的自动操作。

## 1. 原版功能结构

原版 LeagueAkari 是 Electron + Vue + MobX 架构，核心由多个 shard 模块组成。主进程负责 LCU、Riot Client、SGP、窗口管理、设置、托盘和后台任务；渲染端拆成主窗口、OP.GG 窗口、对局小窗、召唤师技能计时器小窗和辅助窗口。

## 2. 可借鉴功能

- OP.GG 独立窗口：英雄强度、克制位、召唤师技能、符文、技能顺序、装备路径，可在 BP 阶段应用方案。
- 对局分析面板：按队伍展示 5 名玩家，支持按位置、组队、Akari Score、KDA、胜率排序。
- 玩家卡片：头像、段位、胜率、KDA、位置偏好、近期英雄、历史标签、组队标签、连胜/连败、高胜率、隐私等状态。
- 战绩卡片：一局比赛内展示英雄、技能、符文、装备、KDA、参团、伤害占比、玩家列表，并可展开更详细数据。
- 小窗体系：BP/对局/技能计时器通过独立窗口轻量展示关键信息。
- 数据层：LCU 本地接口提供当前客户端状态；SGP 补充跨区战绩、详细对局和排位统计；OP.GG 提供公开英雄统计。

## 3. 暂不移植或谨慎移植

- 自动选英雄、自动禁用、自动接受、自动聊天、自动设置符文和召唤师技能：这些属于操作型功能，容易越过“辅助理解”边界，先不做。
- 游戏内覆盖计时器：功能本身可以做，但要确保只是手动记录和提醒，不读取或推断不可见信息。
- 账号/玩家标记同步：可以本地做，但不需要服务器。

## 4. LeagueAkari Plus 第一阶段移植优先级

1. 对局页玩家卡片升级：排序、标签、风险提示、最近表现摘要。
2. OP.GG 方案详情升级：加入 counter、完整符文/技能/装备列表和来源状态。
3. 战绩详情升级：把总览、详尽表格、符文、事件、构建、线图做得更像原版。
4. 小窗草图：仅展示 BP/对局摘要，不做自动操作。
5. 设置页：数据源、显示偏好、排序方式、隐私显示。

## 5. 当前已移植

- LCU 连接与 WeGame 兜底发现。
- BP 双方阵容、Ban/Pick、阵容胜率解释。
- 队友质量分析。
- 近期战绩与对局详情 tabs。
- OP.GG 实时英雄方案读取和本地快照回退。

## 6. 下一步

先做“对局页玩家卡片升级”。这部分完全可以用样例和已有缓存离线验证，不需要登录 LOL 客户端。

## 7. 设置与 UI 设计补充

原版设置中心不是单页堆功能，而是按功能域拆成多个面板：

- 应用设置：语言、主窗口关闭策略、背景材质、启动行为、自动连接、日志级别、代理等。
- 对局设置：进入 BP/对局时自动切换页面，战绩队列筛选偏好，玩家隐私状态和对局页显示方式。
- 多窗口设置：小窗口、OP.GG 窗口、对局叠加窗口、计时器窗口分别控制启用、自动弹出、透明度、快捷键和位置重置。
- OP.GG 设置：闪现位置偏好、符文/召唤师技能/装备方案自动应用。LeagueAkari Plus 只保留“只读展示”和“偏好说明”，不自动写入客户端。
- 存储设置：导入导出设置、标记玩家、缓存和用户数据目录说明。

可迁移到 LeagueAkari Plus 的第一批设置：

- 启动后自动连接 LCU。
- 进入 BP 自动切到选人分析。
- 紧凑模式。
- 数据源状态：LCU、WeGame 兜底、OP.GG、SGP 规划。
- 选人分析显示项：阵容维度、队友质量标签、OP.GG 只读方案。
- 窗口规划状态：主窗口、OP.GG 小窗、对局叠加窗口。
- 安全边界说明：明确“会做”和“不会做”。
